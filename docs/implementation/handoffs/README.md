# Task handoffs

Completed, blocked, failed, or rejected task handoffs use the immutable template in `../MASTER_PLAN.md` section 11.2. Each handoff records base/final SHA, branch/worktree, changed files and canonical symbols, exact commands/results, tests not run, scientific/performance evidence, interface changes, assumptions, decisions, risks, remaining work, next exact action, and scope audit.

Do not overwrite an accepted handoff. Corrections are new append-only records that reference the superseded handoff.
