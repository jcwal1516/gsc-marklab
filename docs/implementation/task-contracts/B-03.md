## Frozen policy

1. Local dependency layers descend `marklab` (compatibility/application) → `marklab-workflow` → `marklab-project`; a lower layer cannot depend upward.
2. Non-root core libraries cannot define or use a `cli` feature; the root library's only CLI-gated boundaries remain its exact current adapter, test-module, synthetic-smoke, and launcher files.
3. Repository gates use `--workspace`; package-specific WSI/binary/release commands name `--package marklab`; standalone fuzz remains outside the workspace.
4. Compile matrix: no default, default, all features, CSV without Parquet, Parquet without CSV, CLI without defaults, WSI without CLI, and `wsi,cli`; the existing no-default DHAT gate remains separate.
5. All-feature and affected `cli`-only Clippy deny warnings. Feature-distinct CLI tests remain serial when sharing a target directory.
