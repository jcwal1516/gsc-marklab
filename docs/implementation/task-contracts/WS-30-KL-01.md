## User workflow

marklab classical consumes the existing supported cell table and mask GeoJSON, constructs and validates one explicit bounded 2-D observation window, builds one immediately used reusable geometry plan, declares conditional homogeneous CSR over the whole location pattern, computes border-corrected K/L and deterministic ERL global inference, runs through the existing project scheduler, and atomically writes result.json, run_manifest.json, and report.md.

## Frozen scientific contract

- Estimand: homogeneous Ripley K and L of the retained unmarked simple point pattern in the supplied physical 2-D window.
- Edge correction: standard border/reduced-sample. For area A, n points, m(r) centers with boundary distance at least r, and q(r) ordered distinct pairs from eligible centers with distance at most r, K(r) = A q(r) / (n m(r)) and L(r) = sqrt(K(r) / pi).
- Null: binomial homogeneous CSR conditional on the exact observed n and fixed window. The randomization unit is the entire location pattern. Marks, labels, cells as replicates, and patient inference are not part of this null.
- Simulation: deterministic domain-separated SplitMix64 streams; uniform bounding-box proposals accepted by exact window containment; exact simulation count or typed draw-budget failure.
- Inference: reuse the canonical ERL implementation over available L curves. A radius is inference-eligible only when observed and every simulated curve are available.
- Result values are finite with positive zero. Unavailable values are absent, never NaN/infinity/filler.

## Frozen geometry and resources

- ObservationWindow2D accepts bounded GeoJSON MultiPolygon geometry in micrometres, canonicalizes valid ring orientation, and rejects non-finite/unclosed/too-short/zero-length/zero-area/self-intersecting/touching/crossing rings, overlapping/nested components, and holes outside/touching an exterior.
- Closed-window point membership includes exterior and hole boundary; hole interiors and outside points are excluded.
- Duplicate point coordinates are rejected in version one.
- ObservationWindow2D owns one canonical boundary-segment index. SpatialGeometryPlan2D owns one exact point R-tree, point/window identity, immediately consumed boundary distances, and streaming ordered-pair counting. It stores no all-pairs matrix and does not duplicate the window index.
- Every input byte, component, ring, vertex, point, radius, memory, pair-visit, and CSR candidate-draw bound is checked before successful output commit.
