## Deterministic estimand and availability

Allocate a fallible `E`-element edge-index vector, then sort it in place by `(PatchId, assignment_row, original_edge_index)`. This order is the numeric order. For each represented patch, retain only incidences whose cell embedding status is `Present`.

A patch is eligible when at least two present cell incidences remain. Its centroid is the stored-order arithmetic mean of those vectors. The reported value is the incidence-weighted mean squared component deviation from eligible patch centroids:

`sum_{eligible incidences i} sum_j (x_ij - centroid_patch(i),j)^2 / (eligible_incidence_count * D)`.

Overlapping containment contributes one incidence per exact cell-patch edge and is never described as independent replication. Patches with fewer than two present incidences and every non-present incidence are excluded. `Available` requires at least one eligible patch; otherwise return typed `InsufficientEligiblePatches` with no numeric value. Canonicalize exact zero to positive zero.

Use one reusable fallible `f64[D]` centroid accumulator. Runtime is `O(E log E + E*D)` and exact incremental working storage is the admitted edge-index vector plus one centroid. The conservative `3 * E * D` cap covers two edge/component passes and one dimension pass per possible edge without depending on availability.
