## Semantic compatibility contract

Reject before legacy comparison when any of these differ:

1. Binary stable mark ID.
2. Binary display label.
3. Binary measurement status.
4. Structure-factor or other-endpoint value routing.
5. Optional probability presence, stable mark ID, or measurement status.
6. Binary origin class; for thresholded origins, source probability ID, comparator, or exact `f32::to_bits` threshold.

Errors are typed categories and expose no mark IDs, labels, thresholds, artifact IDs, cell IDs, slides, or frames.

Before those cross-output checks, reject a pre or post runtime wrapper when its result row count differs from its scalar identity, its result mark label differs from its binary declaration, or its declared identity digest does not recompute from the attached mark-use value. This is the strongest nonbreaking check available on the existing public-field runtime type; it is not receipt authority for arbitrary same-row/same-label result substitution.

Exact binary/probability provenance and threshold-evidence artifact IDs may differ between pre and post when the semantic definition and status agree. Both mark-use values are retained unchanged so those separate evidence chains remain observable.
