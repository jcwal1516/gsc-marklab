```text
mean_squared_component_difference = sum_j((f64(p[j]) - f64(r[j]))^2) / f64(D)
```

- Visit components in ascending stored order; promote each `f32` to `f64`; perform subtraction, multiplication, and sequential addition; divide once; canonicalize signed zero.
- Promise repeat determinism only. Component reordering and general rotation are not claimed bitwise invariant.
- Preflight the conservative exact `D` component-operation count after every binding. Exact `D` passes; `D - 1` fails even when a path is non-present, so missingness cannot evade the cap.
- `Available` carries `Some(value)` only when both singleton vectors are present. Otherwise `InsufficientComparablePaths` carries `None`, both exact `EmbeddingStatus` values, and no arithmetic.
- Runtime is `O(D)` with `O(1)` additional retained state and no allocation.
