## Deterministic estimand and availability

Allocate one fallible `E`-element edge-index vector and sort it by `(PatchId, assignment_row, original_edge_index)`. Visit patches in that canonical order. For each patch, accumulate declared nucleus area as `f64` separately for exact binary `1` and `0` incidences. A patch is eligible only when both groups have at least one incidence. Its contrast is `marked_mean - unmarked_mean`. The endpoint is the sequential `f64` sum of eligible patch contrasts divided once by eligible patch count, so every eligible producer-declared patch has equal descriptive weight. Exact zero is canonical positive zero.

`Available` requires at least one eligible patch. Otherwise `InsufficientEligiblePatches` carries no numeric value. Report represented/eligible patch counts; eligible marked, unmarked, and total incidence counts; and excluded incidence count. Overlapping patches repeat exact cell incidences and are explicitly not independent replication.
