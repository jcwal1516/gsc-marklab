## Objective and immediate production caller

Introduce only the four canonical measurement-origin states required by FND-04 and make the C-05 morphology/derived distinction observable. The immediate production caller in this same milestone is a bounded descriptive computation over an existing patch embedding table and its exact declared overlap support. No standalone validator or unused schema surface is authorized.

The computation reports mean squared Euclidean embedding distance across eligible canonical positive-area patch-overlap edges. It is descriptive infrastructure-to-science integration, not a variogram, spatial-autocorrelation coefficient, inferential test, biological endpoint, or real-corpus result.

## Frozen status and binding contract

- `MeasurementStatus` is a closed in-memory enum: `Measured`, `ImportedPrediction`, `MorphologyPrediction`, `DerivedSummary`.
- It never replaces or aliases `EmbeddingStatus::{Present, MissingVector, ExtractionFailed, QcRejected}`.
- `MultiscaleEmbeddingProvenance::measurement_status()` maps `DirectPatch` to `MorphologyPrediction` and all three deterministic derived variants to `DerivedSummary`.
- The patch computation requires an explicit declared status equal to the provenance-derived status and then requires direct-patch provenance.
- Table owning slide, dimension, provenance digest, expected-set artifact, and support artifact must agree with provenance. Support variant/slide/logical identity must agree with the table. Expected-set artifact/digest must agree between table and graph. Support footprint and overlap bindings must agree with the graph.
- Binding and status failures occur before the work-budget check and before arithmetic. A graph endpoint absent from the canonical table is an expected-set mismatch.

## Frozen numeric and availability contract

For each canonical graph edge with two `Present` rows:

1. Visit components in ascending column order.
2. Promote each `f32` component to `f64`.
3. Compute `(left - right) * (left - right)` and add sequentially to that edge's squared Euclidean distance.
4. Add edge distances sequentially in canonical graph order.
5. Divide once by the eligible-edge count and canonicalize signed zero positive.

Every edge with at least one non-present endpoint is excluded. A present all-zero vector remains eligible. The output records total, eligible, and excluded edge counts. With zero eligible edges it returns status `InsufficientPairs` and `None`; otherwise it returns `Available` and one finite value.

Required work is checked `u64(edge_count) * u64(dimension)`, including potentially excluded edges so status patterns cannot evade the cap. The caller supplies the maximum. Equal succeeds; one less returns the typed work-budget error before row traversal. The implementation retains no pair/vector copy and adds no unbounded allocation.
