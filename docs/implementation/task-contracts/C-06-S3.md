## Estimand and availability

For every canonical nonzero `PatchRegionDeclaration` whose source patch and finalized region rows are both present:

1. Convert the declared fraction exactly as `(numerator as f64) / (denominator as f64)`.
2. Promote each source and materialized region `f32` component to `f64`, subtract, square, and add in component order.
3. Multiply the relation distance by the declared fraction and sequentially add weighted distance and weight in canonical link order.
4. Divide once by total eligible declared weight and canonicalize signed zero.

Non-present source rows are excluded. Present zero vectors are valid contributors. Positive eligible weight returns `Available`; zero eligible weight returns `InsufficientContributors` and no number, never NaN.

This is descriptive fraction-weighted dispersion around an already finalized producer-declared region mean. It is not geometric region proof, a variogram, autocorrelation, an observation-window endpoint, an independent-patch estimate, inference, embedding quality, or biology.
