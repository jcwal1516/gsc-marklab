- Independent binary has no probability column. Probability mode requires thresholded binary plus the exact source probability declaration.
- The record schema is marklab.declared_scalar_mark_table version 1; the table manifest, metadata, provenance dependencies, content kind, and managed bytes must match exactly.
- Canonical Arrow uses V5 file IPC, 64-byte alignment, no dictionaries, compression, field/schema metadata, nullable arrays, or batches over 8,192 rows.
- Verification scans managed store bytes against the live declared input and returns an unforgeable artifact-bound receipt. It does not expose a general Arrow importer.
- Binding the receipt adds its ArtifactId to existing semantic store verification and cache identity. Existing provenance roles remain verified.
- The existing analysis, config 0.2, Pattern, CLI, and result 0.3 codec are unchanged.
