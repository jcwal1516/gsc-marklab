## Input contract

- Borrow one unchanged `Pattern`; do not copy mark, probability, or coordinate arrays.
- Require one strictly increasing typed `CellId` per Pattern row, one explicit owning `SlideId`, and project hierarchy ownership for every cell.
- Require a project-installed coordinate frame that is exactly physical, two-dimensional, micrometre, axes `[X,Y]`; no frame/unit inference from field names.
- Require positive caller maxima for row count and total CellId text; check arithmetic and exact/one-short edges before traversal.
- Validate required per-row arrays and active probability density/finite `[0,1]` semantics before engine construction.
- Reject per-cell `MeasurementStatus::DerivedSummary`. Keep measurement origin independent of value presence; version one has no scalar missing rows.

## Mark and provenance contract

- Stable mark IDs are bounded ASCII tokens. The binary display label is bounded nonblank text and must equal config 0.2 `analysis.mark_label` at execution.
- Binary origin is `Independent` or thresholded from the exact probability declaration with `>` or `>=`, one finite `[0,1]` `f32` threshold, and mandatory threshold provenance.
- Thresholded binary and source probability have identical measurement status and exact rowwise comparator agreement. Binary-only execution accepts independent binary only. Probability execution requires both declarations.
- Mark records use exact C-03 schema `marklab.scalar_mark_provenance` version 1; threshold evidence uses `marklab.scalar_threshold_provenance` version 1. Both reject table manifests and require exact task-owned semantic metadata. Thresholded binary provenance depends on probability provenance and threshold evidence; threshold evidence depends on probability provenance.
- All semantic artifact roles are distinct. Catalog presence/metadata validation precedes node creation; the scheduler's existing retained store verification precedes cache lookup and execution.

## Routing and compatibility contract

`DeclaredMarkUse` must report:

- probability for structure-factor spectrum and its value permutations only when config probability mode is active;
- binary for counts/prevalence/QC, mark-pair covariance, anisotropy, periodogram, multiscale residuals/territories, diagnostics, and all other current endpoints.

`AnalysisEngine::analyze_declared_scalar_pattern` delegates to `analyze_pattern_run` without mutating Pattern or algorithms. Its inner result and actual thread count match the legacy path exactly. Its compact runtime identity exposes row count, ordered-CellId digest, owning slide, coordinate frame, and the full declared-input digest without copying row arrays.

`DeclaredMarkedAnalysisNode` is separate from `MarkedAnalysisNode`. Its ordered reference inputs are the existing compatibility Pattern identity, one version-one declared-input identity, and config 0.2 identity. Semantic inputs are binary provenance, optional probability provenance, and optional threshold evidence in fixed role order. Cache hits/misses return a runtime wrapper with the node-bound declared identity and mark-use summary. The codec encodes only the inner `ResultDocument::marked` 0.3 bytes and reattaches both runtime values after decode; it does not claim durable mark provenance.
